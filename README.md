# مغامرة قائد الحساب | Math Captain Adventure

لعبة تعليمية تفاعلية عن ترتيب العمليات الحسابية: عوالم ومستويات، أنواع تحديات متنوعة (اختيار، توصيل، كتابة الإجابة، صح/خطأ، ترتيب)، تلميحات وشرح، وشهادة في النهاية باسم الطالب.

An interactive educational game about the order of operations: worlds and levels, varied challenge types, hints and explanations, and a final certificate with the student's name.

**Live:** https://qaid-alhisab.surge.sh

## Tech
HTML, CSS and JavaScript in one self-contained `index.html`. Works offline in any browser.

## Run
Open `index.html` in any browser.
